# 🍳 Recipe

A modern recipe browsing and shopping application built with React.js.

The project allows users to explore recipes, add their own recipes, add recipes to a cart, manage quantities, and proceed through an order flow.

---

## 🚀 Features

- 🏠 Modern recipe homepage
- 🍽️ Featured recipe section
- 🔎 Recipe browsing interface
- ➕ Add new recipes
- 🖼️ Upload recipe images
- 🛒 Add recipes to cart
- ➕➖ Increase/decrease cart quantity
- 💾 Persistent data using LocalStorage
- 💰 Dynamic cart subtotal and total
- 📦 Order summary
- ✅ Order success page
- 📱 Responsive UI
- 🧭 Client-side routing with React Router
- 🎨 Modern orange-themed UI built with Tailwind CSS

---

## 🛠️ Tech Stack

### Frontend

- React.js

- React Router DOM
- React Hook Form
